# CONTRIBUTING TO MAHE V2

First off, thank you for considering contributing to MAHE V2!

## Development Process

1. Fork the repo and create your branch from `main`.
2. Install dependencies using `make install`.
3. If you've added code that should be tested, add tests.
4. If you've changed APIs, update the documentation.
5. Ensure the test suite passes (`make test`).
6. Ensure code passes linting (`make lint`).
7. Issue that pull request!

## Code Style

We use `black` for formatting and `ruff` for linting. We strictly enforce type hints checked via `mypy`.

## Pull Request Process

- Describe your changes in detail in the PR description.
- Link any relevant issues.
- A maintainer will review your code.
